Distintas Perspectivas de la Visualización
La visualización es la representación visual estática o interactiva de datos
abstractos o espaciales para reforzar la cognición humana
Michelle Borkin

La visualización es el uso de representaciones visuales e interactivas de datos
abstractos, asistidas por computadora para amplificar la cognición

Stuart Card et al

La visualización proporciona una representación visual de conjuntos de datos
diseñados para ayudar a las personas a realizar tareas de manera más eficaz

Tamara Munzner

Elementos comunes de la visualización
En una visualización podemos identificar varios elementos que se relacionan entre sí:
Datos
La visualización parte de datos que queremos comprender o
analizar
Representación visual
Los datos se transforman en elementos gráficos que podemos percibir
Interacción
Podemos modificar la representación para explorar los datos desde
distintas perspectivas
Cognición
La representación busca aprovechar nuestras capacidades
perceptuales y cognitivas
Tareas y propósito

La visualización está orientada a una finalidad: explorar, comparar,
identificar patrones, comunicar, etc
Tecnología
Las herramientas computacionales permiten construir, transformar
e interactuar con las representaciones

¿Por qué necesitamos visualizar?
Los datos pueden ser difíciles de interpretar directamente
Cuando aumenta la cantidad, complejidad o dimensionalidad de los
datos, resulta difícil encontrar relaciones observándolos como valores
aislados
La representación visual permite percibir estructuras
Una representación adecuada puede hacer visibles patrones,
tendencias, agrupamientos y anomalías
La visualización amplía nuestras capacidades de análisis
Nos permite utilizar nuestra percepción como apoyo para explorar,
comparar y razonar sobre los datos

Metas de la Visualización
Comunicación
Presentar información y transmitir hallazgos
Análisis y exploración
Apoyar el razonamiento y la búsqueda de patrones
✓ Confirmación
Permitir contrastar hipótesis y verificar resultados
Registro/almacenamiento
Mantener información disponible mediante una representación
visual que apoye el razonamiento
Una misma visualización puede cumplir más de una meta

Exploración vs Comunicación
Exploración: aún estamos buscando qué hay en los datos
✓ Buscar patrones
✓ Encontrar anomalías
✓ Comparar alternativas
✓ Formular hipótesis
✓ Hacer nuevas preguntas
Comunicación: ya tenemos algo que queremos transmitir
✓ Explicar resultados
✓ Resumir información
✓ Destacar hallazgos
✓ Facilitar decisiones
✓ Contar una historia

Visualización de Datos e Infografía
Infografía y visualización de datos comunican información a través de gráficos

Infografía
✓ Combina gráficos, texto, imágenes y elementos de diseño
✓ Suele construir una narrativa
✓ La composición y el diseño tienen un papel importante
Visualización de datos
✓ Se centra en representar datos mediante recursos visuales
✓ Puede utilizarse para explorar, analizar o comunicar
✓ Busca facilitar la interpretación de patrones, relaciones y tendencias
No son categorías excluyentes: una visualización puede formar parte de una infografía

Dos grandes contextos de visualización
Visualización científica
✓ Trabaja principalmente con fenómenos del mundo físico o científico
✓ Vemos Mediciones, simulaciones, modelos, fenómenos espaciales o
temporales
✓ Aplicado en medicina, meteorología, ingeniería, física
Visualización de información
✓ Trabaja principalmente con datos abstractos o estructurados
✓ Vemos registros, categorías, relaciones, métricas
✓ Aplicado en negocios, finanzas, redes sociales, dashboards

✓ Visualizar es representar datos para facilitar su comprensión
✓ Toda visualización tiene un propósito: explorar, analizar,
comunicar o confirmar
✓ La percepción humana es fundamental para interpretar
representaciones visuales
✓ Visualizar puede revelar patrones y relaciones que no son
evidentes en los datos originales
✓ La visualización es interdisciplinaria y combina datos,
